
# Dondlinger VS Code Extension

Dondlinger is a VS Code extension that provides Copilot-like inline code completions and chat, powered by the Llama API.

## Features
- Inline code suggestions as you type (Copilot replacement)
- Chat sidebar for Llama completions
- File operation commands (read, write, edit, delete)
- Configurable API URL and key

## Usage
1. Install the extension (`.vsix` or from source)
2. Set your Llama API URL and API key in the extension settings
3. Use inline completions or open the chat sidebar via the Command Palette

## Requirements
- Valid Llama API endpoint and key

## Extension Settings
- `dondlinger.apiUrl`: Llama API URL
- `dondlinger.apiKey`: Llama API Key
